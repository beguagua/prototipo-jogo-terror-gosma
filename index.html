Downloads de conteúdo do jogo

O jogo consulta a API pública do Poly Haven, encontra arquivos reais e os guarda no armazenamento do navegador para reutilizar depois. Selecione um pacote e confirme o download. Requer internet e HTTPS/localhost.

Nenhum download iniciado.

    Limite de segurança: até 120 MB por operação. O navegador pode apagar dados se faltar espaço. Modelos GLB baixados são carregados automaticamente no cenário após o download. Texturas e outros formatos ficam guardados, mas ainda precisam de mapeamento específico para materiais.

    Créditos: Poly Haven — conteúdo CC0; a API exige crédito “Powered by Poly Haven”.

    O armazenamento offline depende do navegador e do espaço livre. Use HTTPS ou localhost para ativar o cache. Não há garantia de que o iPad mantenha 5 GB em cache.
